# Napi Hírlevelek - Signalok (2026-08-06)

Forrás: TLDR AI, 2026-08-05

### Google Cloud API Gateway: egységes AI model routing

A Google Cloud API Gateway publikus preview-ban OpenAI-kompatibilis kéréseket tud fogadni, majd Gemini, Claude vagy OpenAI OSS-GPT modellek felé route-olni. Ez KKV oldalról azért érdekes, mert az AI infrastruktúra egy része elkezd szabványosodni: a vállalkozás nem egyetlen modellhez kötődik, hanem szabályok alapján választhat olcsóbb, gyorsabb vagy erősebb modellt. Gyakorlati haszon: költségkontroll, token tracking, rate limiting és fokozatos modellcsere egy helyen.

### Cloudflare Wallets: kontrollált pénztárcák AI agenteknek

A Cloudflare Wallets stabil identitást és korlátozott fizetési jogosultságot adna AI agenteknek API-khoz, MCP eszközökhöz és online tartalmakhoz. A spending limit, allow list és transaction cap pontosan az a kontrollréteg, ami KKV-nál kell, ha agentek külső szolgáltatásokat használnak. Ez a téma közvetlenül kapcsolódik a biztonságos agent-működéshez: nem az a kérdés, hogy az agent tud-e fizetni, hanem az, hogy mennyit, mire és milyen szabályok mellett.

### Kiro Crew: tartós fejlesztői workspace és ütemezett agent munka

A Kiro Crew egy persistent workspace fejlesztési munkára, amely képes több sessionön át folytatni feladatokat, lokálisan vagy távolról futni, és Slack/Discord jellegű csatornákhoz kapcsolódni. A fontos minta: az agent nem egyszeri chatablak, hanem ütemezhető, visszatérő, állapotot tartó munkakörnyezet. Ez nagyon közel van ahhoz, amerre a Navibase agent-operáció is tart: folyamatos háttérmunka, csak akkor jelezve, ha döntés vagy beavatkozás kell.

### Computer-use verification: bizonyítás képernyőképpel és reprodukcióval

A computer-use verification arra ad mintát, hogy a coding agent ne csak kódot írjon, hanem reprodukálja a hibát, validáljon specifikáció ellen, és képernyőképet vagy videót csatoljon a review-hoz. KKV-s projektben ez csökkenti a bizalmi szakadékot: az ügyfél nem azt hallja, hogy "kész", hanem lát egy ellenőrzött bizonyítékot.

### LFM2.5-2.6B: kisebb, helyben futó agent modell

Az LFM2.5-2.6B egy on-device agentic modell, amely telefonon vagy CPU-n is futhat. A jel nem az, hogy minden KKV-nak saját modellt kell futtatnia, hanem az, hogy a privát, alacsony késleltetésű, olcsó edge-agentek piaca gyorsul. Ez később fontos lehet olyan ügyfélfolyamatoknál, ahol adatvédelmi vagy költségokból nem ideális minden kérést nagy felhőmodellhez küldeni.
